# 微分ドリル — 類題自動生成＋誤答パターン診断

微分の練習問題を自動で作り、間違えたときに「なぜ間違えたか」を指摘する Web アプリです。
AI・LLM の API は使わず、数式処理（SymPy）とルールだけで動きます。

## 特徴

- **問題の入力が不要**：8種類の問題の型（ひな形）から、係数や関数を変えた類題を無限に作ります。
- **誤答パターン診断**：「積の微分を u'v' にした」「合成関数で内側の微分を掛け忘れた」など、
  よくある間違い17種類を式として用意し、解答と一致すれば原因と正しい公式を表示します。
- **形が違っても正しく判定**：答えを展開・因数分解した形で書いても、数式として等しければ正解にします。
- **間違えた型を優先して復習**：型ごとにライトナー方式（間隔反復）で次の復習日を決め、
  「復習」タブでは期限が来た型・苦手な型から出題します。
- **成績画面**：型ごとの正答率、習熟度、多い間違いを一覧できます。

## 問題の型

| 型 | 例 | 主な誤答パターン |
|---|---|---|
| 多項式 | $-3x^5 + 5x^3 + 9$ | 指数を前に出し忘れ／指数を減らし忘れ／定数項を残す |
| 負・分数の指数 | $\frac{6}{\sqrt{x}}$、$-\frac{3}{x^3}$ | 指数を1増やす／分母だけ微分する |
| 積の微分 | $x \ln x$ | $u'v'$ にする／片方の項が抜ける／引き算にする |
| 商の微分 | $\frac{\sin x}{e^x}$ | 分子の順序が逆／分母の2乗を忘れる／$\frac{u'}{v'}$ にする |
| 合成関数の微分 | $e^{5 - x^2}$、$\ln(5x+2)$ | 内側の微分を掛け忘れ／cos の符号ミス／$\sqrt{\ }$ の $\frac{1}{2}$ を忘れる |
| 三角関数 | $-3\sin 3x + \cos 2x$ | cos の符号ミス／sin・cos の符号を逆に覚えている |
| 指数・対数関数 | $4 \cdot 2^x$、$\ln(4x^3+2)$ | $\ln a$ を掛け忘れ／べき関数の公式を使う |
| 積＋合成関数 | $x^3 \sin 2x$ | 上記の組み合わせ |

## 使い方

Python 3.10 以上が必要です。

```sh
python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS / Linux
source .venv/bin/activate

pip install -r requirements.txt
uvicorn drill.api:app --reload
```

ブラウザで http://localhost:8000 を開きます。

- 解答は数式エディタ（MathLive）で入力します。分数・累乗・関数などは、解答欄の下のボタンからも入力できます。
  キーボードでの入力方法は画面の「入力方法」に載っています。
- 「テキストで入力する」に切り替えると `3x^2 + 2sin(x)` のような文字でも入力でき、入力中の式がどう読み取られるかが表示されます。
- 解答履歴は `drill.db`（SQLite）に保存されます。保存先は環境変数 `DRILL_DB` で変えられます。

### テスト

```sh
pytest
```

全ての型を多数のシードで生成し、次のことを確かめています。
- 正解が正解と判定されること
- 各誤答パターンの式が、その原因として診断されること
- 正解と誤答、誤答どうしが同じ式にならないこと

### 評価

```sh
python -m scripts.evaluate 200
```

型ごとに、正解・誤答の判定率、1問あたりの診断できる誤答パターン数、処理時間を測ります。
結果は [docs/evaluation.md](docs/evaluation.md) にまとめています。

## 仕組み

```
drill/
  templates.py   問題の型と誤答ルール。乱数から 問題・正解・誤答の式・解き方 を作る
  checker.py     解答の文字列を SymPy の式に変換し、数式として等しいかを判定する
  diagnosis.py   解答を正解・誤答の式と照合する
  scheduler.py   型ごとの復習スケジュール（ライトナー方式）
  db.py          解答履歴と復習状態の保存（SQLite）
  api.py         Web API（FastAPI）と画面の配信
static/          画面（HTML/CSS/JavaScript、KaTeX・MathLive は CDN から読み込み）
tests/           pytest
scripts/         評価スクリプト
docs/            評価結果
```

- **問題の生成**：問題 ID は `<型>-<シード>` で、同じ ID からは常に同じ問題が作られます。
  そのため問題自体を保存する必要がありません。
- **誤答の照合**：各型が「その間違いをしたら出てくる答え」を式として作っておきます。
  利用者の解答が正解と等しくなければ、誤答の式と1つずつ比べて原因を特定します。
  係数の組み合わせによって誤答が正解と同じ式になる場合（例：$x^1$ で「指数を減らし忘れ」）は、診断の候補から外します。
- **等価判定**：x に複数の値を代入して数値で比べ、評価できない場合だけ記号的に簡約して比べます。

## API

| メソッド | パス | 内容 |
|---|---|---|
| GET | `/api/types` | 問題の型の一覧 |
| GET | `/api/problem?type=<型>` | 新しい問題（型を省略するとランダム） |
| GET | `/api/review` | 復習スケジュールに基づく次の問題 |
| POST | `/api/answer` | `{problem_id, answer}` を送ると正誤・診断・解き方を返す |
| GET | `/api/preview?text=<解答>` | テキストの解答がどの式として読み取られるか |
| GET | `/api/stats` | 型ごとの正答率・習熟度・多い間違い |
